# КАПИТАНЫ ОСТРОВОВ — Морской бой с Боссом

Морской бой в тёмной морской теме (глубокий синий, латунь, золото) с двумя режимами:
классический бой против бота и бой с боссом — Кракеном, у которого своё видение моря,
карточки усилений и щиты.

Игра написана на чистом HTML + CSS + JavaScript (Canvas 2D), без сборки и зависимостей.
Открыть `index.html` в браузере — и всё работает.

## Классический режим (против бота)

- Поле 10×10, флот: 1×4, 2×3, 3×2, 4×1 (как в классике).
- Расстановка: вручную (клик по клетке, кнопка «⟳ Повернуть») или «⚓ Авто» —
  компьютер расставит весь флот сам.
- Попал — стреляешь ещё раз. Убил корабль — обстрел окрестностей автоматом.
- Доски сами переворачиваются: твой ход — впереди море противника,
  ход бота — впереди твой флот. Никаких лишних кнопок.

## Босс-режим: Кракен

- Тот же флот 4-3-2-2, у флота 11 палуб жизни, у Кракена — 9.
- Кракен невидим: где-то в море прячется зона 3×3. Пусть и мимо — он рыбачит:
  каждые пару твоих выстрелов поднимается, бьёт по твоему флоту и ныряет в новое место.
- Когда Кракен всплыл — стрельба по нему разрешена и только по зоне 3×3.
- Карточки усилений (по одной на бой, как настоящие карты: иконка, название, эффект, счётчик):
  - 🛡 **Щит** — ставит щит на клетку. Первое попадание Кракена туда гасится,
    щит с треском разбивается, второй удар уже бьёт по-настоящему.
  - 📡 **Радар** — подсвечивает сектор, где прячется Кракен.
  - 🚀 **Торпеда** — бьёт по всей линии (строка или столбец).
- Победа — отнять у Кракена все 9 жизни раньше, чем он разобьёт твой флот.

## Структура и «пазлы»: как добавлять обновы

Каркас собран по реестровому принципу: `index.html` знает только реестр `CPT`,
модули регистрируются в нём сами.

- `CPT.mode({ id, name, desc, icon, start })` — новая кнопка в главном меню.
- `CPT.painter(fn)` — новый художник в общий игровой кадр (общий
  `requestAnimationFrame` в `game_core.js` вызывает всех зарегистрированных).
- `CPT.lore({ title, text })` — новая историческая справка в меню.

Чтобы добавить новый режим (например, «Дуэль на живых кораблях»):

1. Положить в папку новый файл `duel_ships.js`.
2. В конце `index.html` добавить одну строку рядом с остальными:
   `<script src="duel_ships.js"></script>`
3. Больше ничего не трогать: кнопка режима появится в меню сама,
   механика старых режимов не переписывается.

Старые версии не теряются: GitHub хранит всю историю коммитов.
Для наглядности можно складывать архивные копии в подпапку `archive/`.

## Запуск

- Локально: просто открыть `index.html` двойным кликом. Интернет не нужен.
- На GitHub Pages: Settings → Pages → Source: ветка `main`, папка `/ (root)` —
  и игра доступна по ссылке вида `https://имя.github.io/репозиторий/`.
  Если игра лежит в подпапке — ссылка `.../репозиторий/имя-папки/`.

## История версий

### v2.0
- Каркас-реестр `CPT`: режимы, художники и справки добавляются как пазлы,
  без переписывания механики.
- Карточки усилений вместо серых кнопок: рисованные иконки, название,
  описание, счётчик, три состояния (готова / выбрана / использована со штампом).
- Щит стал честным одноразовым: иконка на клетке → поглотил удар →
  разбился с осколками → следующий удар по клетке обычный.
- Доски автоматически переворачиваются к тому, чей сейчас ход, в обоих режимах.
- В классическом режиме возвращена кнопка «⚓ Авто» (полная автарасстановка).
- Версия вынесена в одно место (`CPT.version`) и видна в меню — больше никаких
  «6 версия» на кнопках.
