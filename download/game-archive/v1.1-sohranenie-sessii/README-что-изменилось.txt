ОБНОВЛЕНИЕ v1.1 — Сохранение сессии сборки
Дата: 12.11.2026

ЧТО НОВОГО:
1. Незаконченный пазл больше не пропадает: каждая деталь
   запоминается после каждого хода. Закрыл игру — открыл —
   на главном экране кнопка «Продолжить: [пазл] N из M».
2. Поворот телефона / изменение размера окна не сбрасывает
   прогресс: позиции хранятся в долях поля.
3. Пазл открывается сразу на той сложности, на которой играл
   (если есть незаконченная сессия), иначе — на простой (6).
4. Плашка «Появилось обновление!» — при новых версиях игроки
   видят кнопку «Обновить» на главном экране (один тап).
5. Номер версии в подвале главного экрана (v1.1).

ИЗМЕНЁННЫЕ ФАЙЛЫ (структура как в проекте):
src/lib/game-services.ts        — сохранение/чтение/очистка сессии
src/lib/puzzle-data.ts          — константа APP_VERSION
src/components/game/PuzzleBoard.tsx — автосохранение + восстановление
src/components/game/MenuScreens.tsx — кнопка «Продолжить», плашка
                                      обновления, версия в подвале
src/app/page.tsx                — открытие пазла на нужной сложности
src/app/api/version/route.ts    — НОВЫЙ файл, проверка обновлений

Проверено в браузере:
- перетаскивание сохраняется и восстанавливается после перезагрузки
- кнопка «Продолжить» открывает пазл с прилипшими деталями на местах
- смена размера окна не сбрасывает сборку
- плашка обновления появляется и исчезает после «Обновить»
